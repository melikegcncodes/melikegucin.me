# 🌐 MelikeGucin.me – Kişisel Portföy Web Sitesi

MelikeGucin.me, kişisel projelerimi, yeteneklerimi ve dijital kimliğimi sergilemek amacıyla geliştirilmiş modern bir portföy web sitesidir. Bu proje, hem frontend geliştirme becerilerimi geliştirmek hem de gerçek bir domain üzerinde yayınlama (deployment) deneyimi kazanmak için oluşturulmuştur.

---

## 📌 Proje Amacı

Bu projenin temel amacı:

- Kişisel bir portföy sitesi oluşturmak  
- Web geliştirme becerilerini pratikte uygulamak  
- HTML, CSS ve temel frontend teknolojilerini pekiştirmek  
- Kendi dijital kimliğimi oluşturmak  

---

## 🚀 Proje Özellikleri

Bu web sitesi aşağıdaki özelliklere sahiptir:

- 📱 **Responsive Tasarım:** Mobil, tablet ve masaüstü cihazlarla uyumludur  
- ⚡ **Hızlı ve Hafif Yapı:** Gereksiz kütüphaneler kullanılmadan optimize edilmiştir  
- 🎨 **Modern Arayüz:** Sade ve kullanıcı dostu tasarım anlayışı  
- 🧭 **Kolay Navigasyon:** Kullanıcıların içeriklere hızlı ulaşmasını sağlar  
- 🌍 **Canlı Domain:** Gerçek bir domain üzerinde yayınlanmaktadır  

---

## 🛠️ Kullanılan Teknolojiler

Proje geliştirilirken aşağıdaki teknolojiler kullanılmıştır:

- HTML5 (Yapısal iskelet)
- CSS3 (Stil ve tasarım)
- JavaScript (Varsa etkileşimler)
- Responsive Design (Mobil uyumluluk)
- Linux Ubuntu VPS (Sunucu ortamı)
- SSH (Güvenli bağlantı)
- SCP (Dosya transferi)
